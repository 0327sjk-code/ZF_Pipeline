# ZF_Pipeline

UE 5.7 特效库 / 视频库 / 工程库 Windows 桌面客户端（便携版，免安装）。

## 下载

在 [Releases](https://github.com/0327sjk-code/ZF_Pipeline/releases/latest) 下载 `ZF_Pipeline.exe`，放到可写入的文件夹（如 D 盘）直接运行；数据保存在程序旁边的 `ZF_Pipeline_Data` 文件夹。

## 更新

打开软件会自动检查新版本，有新版本时弹窗提示，确认后自动下载、校验并重启更新；更新没有成功时自动恢复到原来的版本。
也可以在 设置 › 关于 里手动检查更新。
